This opening checkpoint predates the dispatcher/UART reconciliation and the
v10 coordinator corrections recorded below. Its measurements are historical;
its partial-scaffold and six-helper descriptions are not the current state.

1. Added maintained EMOS production objects for the raw forward-parallel data
   plane. A hardware-independent engine chunks bounded streams into raw records
   of at most 4096 bytes. A separate eZ80 binding owns Port C plus PD4/PD5/PD7,
   admits only a live epoch lease, uses the MOS centisecond clock for elapsed
   READY deadlines, and releases CLOCK, VALID, direction, and busy state
   deterministically. No r01 branch, alternate grammar, activation mechanism,
   response path, or silent fallback was added.
2. Added six IFF-preserving assembly helpers for masked Port D updates,
   pin configuration, writer admission, atomic entry start, a four-byte clock
   snapshot, and epoch publication. Interrupt exclusion is confined to these
   small register/state operations rather than spanning READY waits or a whole
   record. The 24-bit epoch generation fails closed at exhaustion.
3. Added a visibly non-release fixed-backend profile. It accepts explicit
   external peer attestation and calls production epoch enter/leave functions,
   but exposes no direct write entry. It is only a partial scaffold until the
   ordinary semantic dispatcher routes RST/C-runtime bytes into the production
   engine.
4. Added deterministic host and structural checks for byte values, record
   boundaries, 65535-byte chunking, cadence, elapsed and stalled-clock
   timeouts, register cleanup, interrupt-state preservation, stale/redundant
   leases, generation exhaustion, entry contention, nested writers, sticky
   deferred failure, and lifecycle recovery. Linked-image checks require
   defined global text entry points and inspect the bounded IFF/mask/clock
   helper shapes. Their output explicitly does not claim source/object origin,
   linker contribution, release identity, or ordinary-dispatcher reachability.

## Initial EMOS-local adversarial corrections before dispatcher reconciliation

1. Entry publication originally could erase a writer fault raised while entry
   was still in progress. Entry now has an atomic begin/commit protocol and
   aborts publication after writer contention.
2. A concurrent leave during entry originally could be overwritten by the
   later entry commit. Leave now invalidates the in-progress entry, and commit
   fails closed.
3. A rejected stale or nested writer originally released its lock before
   publishing the deferred lifecycle fault. The writer now publishes the fault
   before releasing the lock, preventing a new writer from observing a false
   clean state.
4. The EMOS repository wrapper accepted `MOS_WORKTREE` but did not forward it
   into generic firmware targets. The first isolated fixed-profile build
   exposed the mismatch when the default tree lacked the new objects. All
   build and qualification targets now pass the selected worktree, with a
   regression check in the EMOS port tests.
5. Initial linked-image verifiers described more evidence than they proved.
   They now require uniquely defined global text symbols, nonempty production
   instruction extents, exact helper properties, and direct fixed enter/leave
   references while stating the remaining provenance and reachability limits.

Items 1--5 are local implementation or build-tool defects introduced during
this uncommitted production factoring and corrected during the same pass. They
are not defects in official MOS. Stock `open_UART1()` changing the Port C mux
during a live parallel epoch is not classified as an upstream MOS defect: it
is valid in stock MOS's ownership model. EMOS integration must serialize or
reject that API for the entire project-owned epoch before claiming sole mux
ownership.

## Historical INTEG-002 v8 dispatcher and ownership reconciliation

This v8 checkpoint is superseded by v10 below.

1. Replaced the complete predecessor sender path in `src/serial.asm` with the
   common production route bridge. C `putch`, RST 10, and delimited RST 18 use
   the byte dispatcher; bounded RST 18 uses the stream dispatcher. Each
   dispatcher snapshots the coordinator-owned route once. Backend 0 reaches
   only onboard UART0, backend 2 reaches only the private-lease production
   bridge, and unsupported values fail closed without fallback. The bounded
   bridge advances HL, zeros BC, preserves E, and retains the upstream source's
   de-facto successful A=0 result.
2. Retired the predecessor build and link closure. Neither maintained profile
   contains the old sender, adapter, General Poll, spin waits, 4096-byte
   whole-call rejection, register snapshots, or whole-record interrupt mask.
   The old profile filename is a fail-fast tombstone; its ordinary payload
   fixture remains reproducible as historical evidence.
3. Completed the non-release fixed ordinary-VDU composition. The
   operator/top-level prepares the peer before making the explicit Exclusive
   Extended mode request; EMOS has no external attestation channel and does not
   validate the peer independently. The fixed adapter exposes only common-route
   enter, ready, and leave calls. Ordinary bytes still have no supported path
   around the semantic dispatcher.
4. Added a seventh IFF-preserving assembly helper to reserve the common Port C
   transition atomically. `open_UART1()` now reserves that transition before
   its first flag, mux, or UART mutation and publishes UART1 active before
   releasing it. A live or transitioning parallel epoch therefore rejects
   UART1 open with the existing generic UART failure, while UART1 ownership
   rejects parallel entry.
5. The first reconciliation made this UART guard conditional on a source-
   profile macro. That allowed an EMOS ZDS build to contain both Port C actors
   without the exclusion and was a local profile-parity defect introduced in
   this integration, not an upstream MOS defect. The correction makes the
   guard unconditional, registers the parallel owner in every maintained EMOS
   build surface, and adds source/link regressions that reject profile-optional
   ownership.
