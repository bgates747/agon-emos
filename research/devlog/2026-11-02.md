binary API or physical transport. The private EMOS leaf now chooses entry-IFF
variants once, inlines payload clock pairs and uses partial/page loop counts,
retaining READY abort, Port D atomicity/current unrelated bits, interrupt
availability, guarded ownership and all existing edges/cleanup.

about 40% fewer instructions, for 128 extra ROM bytes/zero extra static RAM.
These are model/full-build results, not measured hardware speed. The ordinary
profile excludes the private leaf. P4/mainboard firmware, startup, SD and wiring
are untouched. Generalized async admission and application callbacks remain
later integration work. The reusable instruction test records its own Unix-ms
start/end and monotonic host duration, explicitly outside hardware timing.
