# 2026-09-29 — FWBUG-008 raw SD write dispatch candidate

Extender AUDIT-010 repair A10-RP04 traced public raw-SD selector `0x73` to an
inherited official MOS 3.0.2 defect: `sd_api_writeblocks` calls the read driver.
The bounded EMOS candidate changes that single target to
`_SD_writeBlocks_API`. Source and linked-image guards now distinguish both raw
read/write wrappers and their C drivers.

Six focused ABI tests pass. A fresh candidate-specific prepared tree and the
repository `firmware-check` wrapper produced a verified 128,574-byte image and
passed all configured product linked checks. The broader repository suite is
126/134; all eight failures reproduce unchanged from clean EMOS `8f29bf8`
against the stale default prepared MOS tree, so they are retained as unrelated
baseline inconsistency rather than attributed to this repair.

The `mos-tests` explicit-profile path required a narrow uncommitted harness
correction: stock MOS/map hashes are now asserted only for the default profile,
while an explicit profile remains pinned by its own four hashes. The existing
RST `0x08` selector `0x73` test and separate C `SD_writeBlocks` control then
passed two seeds each. Independent raw-image reads found 512 bytes of `0x6B` in
sector two in every case. Exact candidate and run hashes are retained in
`docs/tasks/FWBUG-008.md`; ignored evidence is under `build/fwbug-008/`.

The selected emulator cases subsequently passed. The Author clarified that
each repair requires physical validation against a commit-pinned installation.
The new `projects/fwbug008-physical` fixture therefore disarms its one-shot
startup before raw access, proves sector 2 precedes the first MBR partition,
retains the sector, exercises selector `0x73`, independently reads its effects,
restores through the separate C `SD_writeBlocks` dispatch, and verifies exact
restoration before reporting. Its 10,288-byte target build passes. No physical
card, firmware installation, reset, flash or destructive-sector run occurred
during preparation; those remain the next RP04 gate.
