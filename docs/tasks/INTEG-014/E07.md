# E07 — Atomic UART transmit leaf

## Executive summary

Retain the 82-byte assembly transmit leaf: large forward uploads now take
**1,070.062 ms versus E05's 1,399.0955 ms (23.52% less time)**. All 384 exact
cases, six selected large-upload observations and three independent wire
captures pass. Both firmware compositions save 24 bytes. Reverse transfer
performance is effectively unchanged. E05's C block/deadline and E06's original
FIFO policy remain; only two firmware source files differ from the E05 image.

This is 49.07% less large-upload time than the original E04 baseline, but still
81.45% more time than today's mainboard result. This is a pure-data improvement,
not transport parity or a measured graphics/Rally speedup. The pre-test firmware is restored and verified. The hardware spoken cue executed with a fresh service receipt. Work is
paused for Author review; E08/E09 have not started.

Today's mainboard endpoint median is 589.715 ms; Extender is 1,070.062 ms.
The six Extender observations span 1,069.982–1,070.103 ms. This comfortably
exceeds the frozen 5% material-improvement floor. The equal-work mainboard
control is stable. The mixed interval includes return handling/scheduling and
must not be interpreted as isolated upload time.

Forward wire occupancy remains 568.880 ms. Permission-to-send idle drops to
483.803 ms, while P4 backpressure now accounts for 15.631 ms (15.626–15.660).
Do not describe this as zero receiver backpressure. It is a small part of the
remaining forward gap, with no byte loss. Reverse span 109.608 ms still includes
69.336 ms with the Agon stopping its peer; the reverse bottleneck remains.
These wire intervals have different framing/scope from endpoint intervals.
