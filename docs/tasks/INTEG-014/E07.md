# E07 — Atomic UART transmit leaf

## Executive summary

The candidate reduces a ready transmit attempt from54–56 to29–31 interpreted
instructions and saves24 bytes in both whole firmware compositions. Across
221,184 inputs per linked image it matches the E05 compiled C's results,
port accesses, interrupt state and ABI preservation. Hardware performance is
not yet measured. E05's C block/deadline and E06's original FIFO policy remain.
