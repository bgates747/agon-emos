# UTX-001 — Native EMOS Legacy UART0 sender integration

The Author requires the generic interrupt-driven UART0 sender to work inside
real EMOS in Legacy mode, enabling unattended hardware testing through Extender.
The installed EMOS baseline leaves only2450 erased trailing flash bytes, so
native build size and preserved services are prerequisites. A RAM-only sender
prototype cannot satisfy the requested integration. No production promotion or
replacement of the maintained EMOS checkout is implied.

AgonDev-specific ELF checks silently.

The baseline compatibility edits are deliberately narrow: emos_request_mode
copies its initial state through memcpy because ZDS rejects aggregate
initialization from a structure expression; mos_OSCLI fallback declarations
precede executable statements for ZDS's C syntax. Native compilation proves
syntax/code generation only. Native-linked behavioral/baud guards and physical
regressions remain unperformed while the baseline cannot link within ROM.

The Author-confirmed Extender procedure docs/procedures/test-appliances.md
governs tests, superseding this branch's inherited mode-in-autoexec test rule.
Use a Pi Python coordinator, explicit CLI invocation, conditional mode selection,
at least one second of monitor settling and complete entry-state restoration.
Never rewrite startup from a runner. All operations require positive bench
ownership and verified recovery; private topology remains in local records.

Integration preserves UART0 parser ownership, UART1 Extender input and EMOS
route/reservation policy. Async access is limited to safe Legacy sessions;
legacy calls, callbacks, IFF preservation, source-memory retention, descriptor
accounting and return fences follow the generic sender contract. Existing
ExCom/ExExt behavior must remain unchanged or reject incompatible async access.
No direct UART bypass may be advertised as an EMOS-supported output route.

Acceptance requires an actual native ROM within131072 bytes, audited RAM and
linked baud/IRQ/ABI checks, then the relevant Console8 regressions on the
Extender bench under Legacy with working remote input/SD and restoration.
